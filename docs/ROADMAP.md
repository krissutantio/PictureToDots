# Feature roadmap

## Highest priority: recognizable portrait dots

The opt-in **Portrait Simplification** prototype is local. Review the matched
proofs and unresolved glasses/eye separation before making it a default or
publishing. See [PORTRAIT_SIMPLIFICATION](PORTRAIT_SIMPLIFICATION.md) for results
and next experiments. Adaptive reference spacing already defaults on for fresh
projects; saved projects retain their own settings.

## Next illustrated mode (deferred by user)

**Illustrated contour / hatching line art** — see
[LINE_ART_REFERENCE](LINE_ART_REFERENCE.md) for the supplied visual target,
requirements and acceptance criteria. Keep the current segmented line-art mode
in the present version. This is a future feature, not a completed capability.

## Secondary UI polish

UI polish candidates are recorded in [UI_DESIGN_NOTES](UI_DESIGN_NOTES.md).
They remain secondary to portrait recognizability; no redesign has started.

## Physical verification

- Calibrate the 60 Maui colors on the user's actual paper. The new default
  numbers come from the supplied retailer chart; sampled RGB remains approximate.
- Print the permanent-symbol key and confirm every character is distinguishable
  with the chosen marker sizes and printer. Test smallest symbols and textures.
- Continue real iPhone installation, Safari/Firefox and marker/paper proof checks.
